# Same-source crossing comparison

On the 19-node Cyclic routes fixture, the merged ELK.ts and original ELK.js kernels in the same SDK wrapper both draw 37 proper crossing incidences. Historical Native draws 23, Zombie Mermaid 5.17.0 draws 31, the installed Pele 1.13.0 npm product draws 38, and the hosted pele.run playground showing version 1.13.0 draws 40. Each result covers the same 44 authored relationship occurrences, including duplicate pairs, and retains all 11 authored caption associations. The static calculation reads the SVG’s decimal coordinates exactly and covers all 946 authored pair combinations. Bézier control hulls first exclude disjoint segments. All of Zombie Mermaid’s 134 quadratic corners have disjoint bounds from every other relationship’s segments. Its 31 crossings lie on straight segments. The npm SVG has 63 genuine cubic segments and the hosted SVG has 61. Fifty-seven line/cubic and 25 cubic/cubic segment pairs survive the first filter for npm, compared with 54 and 24 for the hosted SVG. Univariate real-root isolation and polynomial subresultants determine intersection parameters, which are checked against both segment domains, tangent orientation and whole-route endpoints. Every proper Pele crossing is an interior transverse intersection. There are no unresolved segment pairs. A second implementation seeded with svgpathtools’ subdivision results refines the parameters by Newton iteration and recovers the same pair/location set within 1.41 × 10⁻¹¹ px for npm and 2.64 × 10⁻¹¹ px for hosted.
