## A concrete cumulative ownership simplification

The compound regression exposes three distinct states that were treated as one `pending` path: **provisional quotient guide**, **already-real authored terminal span**, and **finalized leaf route**. A pending edge can contain both a guide and a real terminal; its whole path is neither wholly physical nor wholly imaginary. The existing `lifted` endpoint mapping already distinguishes an authored endpoint from its representative. Authored container endpoints also remain real; node kind alone cannot decide this.

The immediate narrow consumer rule retains an unfinished peer if either endpoint was not changed by lifting. A subsequent cleanup can make these facts explicit within the existing neutral measured request, carrying the terminal reservation from the actual resource preparation to compound completion and publishing only finalized path facts after query leases end. This could remove duplicate path copying/classification and prevent accidental reservation loss; runtime/memory savings remain hypotheses until profiles establish their contribution. Do not introduce a new backend, public trust flag or cache to express this state transition. Labels retain their independent physical reservation throughout, and a failed strategy spends the same original ledger.

## Withdrawn first experiment

The exact finite-axis miss gate in `src/shared/edge-crossings.ts` is behaviorally supported but is being withdrawn. The fan100 probe found 29,106/67,890 general-intersection calls were same-axis misses; chains had zero opportunities. Finite **spans**, not just finite endpoint coordinates, are required because ±1e308 differences can overflow. Ownership trace and raw numeric parity support the narrow gate, but the isolated unprofiled costs do not support retaining it: Sol reports Native fan stock128.42→125.52ms while full155.88→163.11ms and cold319.98→336.87ms worsened; ELK full348.48→383.02ms and cold760.89→810.13ms worsened; Native chain100 full101.90→105.37ms and first edit134.86→174.94ms worsened. These are this run's exploratory medians, not historical-host comparisons. Do not re-run favorable gate variants. Final complete-product equality and raw cost archive belong to Sol's implementation directory.

## Primary-source and peer lessons

- [Pele1.9.0 compound tests, commit e7f092a](https://github.com/obsidianmd/pele/blob/e7f092a4de147cc32210913c20e36eaa5fcd0ef1/tests/layout/compound.test.ts#L588) verify consistent far-side port order in TB/LR and a three-group permutation with zero routed crossings. [Its compound implementation](https://github.com/obsidianmd/pele/blob/e7f092a4de147cc32210913c20e36eaa5fcd0ef1/src/layout/compound.ts#L597) uses a bounded same-direction flat ordering hint, then tests actual routed crossings and restores a prior geometry if a refinement fails. Curved versus stepped ink is distinguished in its tests at570–582. These are verified source/test intentions, not measured Pele superiority on our corpus. The public1.9 source is now available; the missing pinned full rendering comparison remains missing.
- [Pele1.9 marker emission](https://github.com/obsidianmd/pele/blob/e7f092a4de147cc32210913c20e36eaa5fcd0ef1/src/svg/edges.ts#L184) draws a separate8px world-coordinate filled triangle with stroke:none; it does not use SVG markerUnits scaling. [Flowchart emission](https://github.com/obsidianmd/pele/blob/e7f092a4de147cc32210913c20e36eaa5fcd0ef1/src/diagrams/flowchart/render.ts#L322) styles shafts independently and passes only position/tangent/color into marker(). Its arrow therefore does not become32px when a shaft is4px wide, unlike our default marker contract. The per-node-face `sideReach()` at edges.ts33–40 coordinates incident escape room using markerTrim+LEAD, a concrete ownership lesson. It is not evidence that Pele solves our scaled-head capacity case. Preserve our existing visual semantics; do not copy smaller heads to hide the gap.
- [ELK authors, 2023, §3–4](https://arxiv.org/html/2311.00533v1): independent bottom-up child layouts can force incompatible hierarchical port order. Considering cross-hierarchy destinations addresses some cases but conflicts with several direction/order strategies. Explicit phase preconditions and processor dependencies matter; ELK computes rectangle/route geometry, not final glyph/marker/CSS correctness. Transfer the causal boundary, not its entire option system.
- [ELK BKNodePlacer, v0.11.0 commit54123e8](https://github.com/eclipse-elk/elk/blob/54123e884b1ae743b453260f713b20c9bf5787f2/plugins/org.eclipse.elk.alg.layered/src/org/eclipse/elk/alg/layered/p4nodes/bk/BKNodePlacer.java#L213) invokes inside-block shifts for actual ports before compaction. Preconditions include proper layers, optimized node order and arranged ports. This source pin is not an assertion that a particular elkjs artifact was built from exactly this Java revision.
- [Dagre1.1.8 nesting graph, commit7e4d15f](https://github.com/dagrejs/dagre/blob/7e4d15f191678f7f05f3c86d9071a193230e7e00/lib/nesting-graph.js) uses top/bottom borders, nesting depth and minimum spans; [coordinate placement](https://github.com/dagrejs/dagre/blob/7e4d15f191678f7f05f3c86d9071a193230e7e00/lib/position/bk.js#L206) explicitly substitutes a block-graph two-sweep compaction for the original BK compaction. Native already has analogous border and bounded minimum-span machinery; avoid duplicating it.
- [Brandes–Köpf original author PDF](https://kim246.wwwdns.kim.uni-konstanz.de/publications/bk-fshca-01.pdf) gives fast coordinate assignment once layers/order are fixed. [The2020 erratum](https://arxiv.org/abs/2008.01252) corrects two compaction errors without an asymptotic penalty. Its linear complexity concerns the proper expanded graph, not parsing, dummy expansion, routing, paint capture or receipt production.
- [Sander's1996 author exposition](https://www.site.uottawa.ca/ordal/papers/sander/node21.html) explains why independent frames miss global cross-frame relationships and why nondividing layouts require consecutive members and consistent frame order across ranks. Global treatment costs more and limits independent hierarchy parameters. This supports a restricted existing-path extension, not unconditional flattening.
- [Barth–Mutzel–Jünger2004](https://www.jgaa.info/index.php/jgaa/article/download/paper88/2877/2684) reduces bilayer straight-edge crossing counts to inversions. Native's rank-order crossing score already uses this class of indexed counting. It cannot replace final polyline/curve/marker intersection semantics; counting straight two-layer inversions and counting final painted crossings are different problems.
- [Eades–Lin–Smyth1993 publisher record](https://www.sciencedirect.com/science/article/pii/002001909390079O) provides a linear-time feedback-arc heuristic for the stated sparse/simple graph domain. The institutional full-text link was403, so detailed pseudocode was not inspected. [Sugiyama–Tagawa–Toda1981](https://doi.org/10.1109/TSMC.1981.4308636) is the primary historical reference; IEEE full text presented a robot check. Do not attribute unverified algorithm details to either source.
- [Mermaid12.2 pinned geometry](https://github.com/mermaid-js/mermaid/blob/1fb7869866dd619168d840291c9c54b4f129758b/packages/mermaid/src/rendering-util/layout-algorithms/elk/geometry.ts) preserves an orthogonal departure axis when moving an ELK bounding-box endpoint onto a shape outline, falling back when it cannot prove the ray. This reinforces final shape-contact ownership, not pixel parity. [Beautiful Mermaid pinned layout](https://github.com/lukilabs/beautiful-mermaid/blob/2ac8bbbb060ca0a65a6a21f3200bd99b1587b488/src/layout-engine.ts) wraps ELK then applies layer alignment, shape clipping and bundling. It is a differentiated rendering pipeline, not an independent layout algorithm or a correctness oracle.
