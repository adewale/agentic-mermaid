# Stable-family source corpus

These six authored stress sources are source authority for corpus discovery,
benchmarks and visual review. They combine meaningful domain features rather
than repeating the small metadata examples: cross-row bit spans, per-task
metadata, typed traceability, nested authored cells, nested quantitative areas
and causal subtrees. Their labels are retained in full.

The independently pinned upstream oracles and exclusion ledgers live in each
`eval/mermaid-<family>-bench` directory. These inputs assert Agentic's native
contracts; they are not upstream snapshots or generated rendering artifacts.
