# Layout stress fixtures

These eleven authored inputs retain the six graph-family scaling regressions previously used by the layout diagnostic. They are product geometry fixtures, without timing, ranking, release enrollment or benchmark execution. Trident owns benchmark inventories and runs.

`eval/layout-compare/run.ts snapshot --stress` reads this directory through the same fixture loader as the ordinary diagnostic cases. Default snapshots remain unchanged. Existing cyclic, compound and labelled regressions remain in the parent fixture directory.
