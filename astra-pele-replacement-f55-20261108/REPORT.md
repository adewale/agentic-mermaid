# Why Pele can ship without ELK, and what still blocks Native

**Pele has operationally replaced external graph-layout dependencies. It has not established universal superiority over ELK. Native is already competitive enough to be useful; its remaining replacement problem is unsafe interactions between geometry stages, expensive shared product completion, and an objective that mixes hard correctness with winning every quality/resource metric.** More verification explains part of the cost difference; it does not excuse Native's visible contacts.

Separate **1.9.0** source is `e7f092a4de147cc32210913c20e36eaa5fcd0ef1`; neither archive requalifies old npm/site bytes. No builds, installations, tests, benchmarks or geometry probes were run.

**What Pele actually replaces — high confidence from source.** Its public render path parses a registered family and calls that family's renderer; there is no ELK/Dagre runtime dependency or alternate engine handoff ([core:162–187][pcore], [package][ppkg]). Flowchart, Class, ER, State and Requirement all call its own compound layout, which uses its layered solver. Other families have specialized render/layout paths; their support is not evidence about layered-graph parity. Its current documentation lists every built-in Mermaid 12.1 family, including sequence/charts/timelines and newer families, while excluding ZenUML/external plugins ([compatibility:10–48][pcompat]). That is a meaningful product replacement, not an ELK API implementation.

Flowchart uses default curves, optional stepped or linear routes ([render:179–186][pflow]); narrow-container adaptation may change orientation. HTML labels are unsupported, JS click callbacks ignored, Mermaid themes do not apply, configuration support varies, and math requires a supplied resolver or displays TeX source ([compatibility:52–94][pcompat]). These are intentional product choices. Source/output/edge limits and a >20,000-dummy direct-route fallback bound work ([core:35–42][pcore], [layered:273–290][player]). That fallback drops intermediate-rank normalization for long edges; equivalent quality is unproved.

Parser/model compatibility and skipped Mermaid engine-selection tests establish neither inferior output nor geometry parity. Its benchmark compares with Mermaid's renderer, not isolated ELK (`scripts/bench-mermaid.mjs:17–27,111–141`). **Equivalent-work correctness, speed, memory and byte superiority remain unproven.**

**The causal architecture difference.** Pele owns measurement → layout → clipping/markers → SVG. Native replaced the solver inside an existing ELK-oriented product: measured geometry becomes positioned geometry, undergoes shared completion, then Scene/XML/paint proof. Multiple route authorities allow a repair to change the selected candidate or invalidate earlier clearance. Pele also retries layouts; one engine does not mean one pass.

Native **already skips** ELK peer resizing and port-lane movement, and restricts many node-moving passes to ELK/forest paths (`layout-engine.ts:1450–1525`). Saying “all ELK repairs run again” would be false. The narrower problem is residual overlapping completion, not a missing backend switch. Producer-box reuse and route-only forest fan emission are already shipped (`layout-engine.ts:1460–1462,1551`).

**Mutation-boundary check:** ordinary production at `producer-core.ts:105–106` finalizes/shortens and fits only at373. The extra fit at99 executes through the completion callback for eligible cyclic+self-loop search (`agentic-layered-core.ts:196–212`; `cycle-layout-search.ts:60`); subsequent search scores/selects completed candidates, then projection checks shape/finiteness and fits at373. That narrow repeat is a candidate for removal after identity/alias checks. By contrast, shared completion at406 can clip/reroute/reseat labels, so safety certification after it checks a changed artifact and is necessary. Owned refinement certifies candidates at458/469, then its winner is re-certified at501; between those checks the shown path scores/selects and writes selection-cache metadata, not route geometry. `retainSelection` does attach authored-membership/certification metadata (`certification.ts:385–391`), which must be accounted for. These are exact current call relationships; no current causal time saving is established.

Two prior source findings still hold at f55: zero crossings suppress owned refinement even if other defects exist (`producer-core.ts:455–457`); selected internal history is re-certified as `attempts:1`, `first-certified`, `agentic-layered` (`487–501`), despite the receipt defining placement-production attempts (`certification.ts:54`). These impede explanation and policy consistency, not themselves proof of bad geometry. Generic selection puts crossings before label conflicts; owned selection reverses those priorities (`certification.ts:31–34`, `producer-core.ts:459–462`). Fix the selection contract before broadening search. Pele also short-circuits zero-crossing ordering; the useful difference is that its coordinate/label/port work still runs afterward.

**What plausibly makes Pele cheaper.** No external solver bundle; real core/family/lazy boundaries (`scripts/build.mjs:19–38,58–80`); conditional rank expansion; direct SVG production without Native's Scene/XML paint receipt. Earlier endpoint alignment may avoid repairs. These are source mechanisms, not measured savings. Native also has synchronous/lazy paths. Pele's curved routes and direct-long-edge escape change the work; they cannot justify speed ratios. Its measurement caches also rule out assuming zero retention. Native's frozen-pass snapshots and metric checks (`layout/pass.ts:136–150`) protect mutation contracts, but deserve measured accounting.

Existing Native evidence:25/25 successful portable uncached pairs were lower; cached repeats split14/11. Focused Class128 ranges overlap; a fixed11% deficit is unestablished. The actual six-family browser product measured476,485/851,989 gzip and407,052/682,687 Brotli bytes, Native/ELK, with39/37 requests. These compare Native/ELK, **not Pele**. Both retention diagnostics grew. Competitiveness is demonstrated within these boundaries; global replacement is not.

**Tests to learn from.** Pele is MIT(copyright2026 kepano); compatibility specs/grammars derive from MIT Mermaid12.1. Preserve provenance/notices if reusing substantial material; prefer reduced locally authored witnesses:

- `tests/layout/compound.test.ts:588–647`: two-group fan boundary-order agreement and labeled3×5 bipartite border alignment. Extend existing Native compound owners with unequal sizes/reciprocal edges/reversed directions.
- `compound.test.ts:140–160`: forward/backward rank-skipping edges turn once when corridors permit. Native already covers long channels; add marker/label-offset interactions, not duplicate chains.
- `tests/layout/layered.test.ts:5–35`: independently recount crossings and group contiguity; carry checks through final routes.
- `tests/render/flowchart.test.ts:347–401`: reciprocal-arrow separation and diamond/circle attachment. Its stepped point-in-box checks do not prove every segment/stroke clear; keep Native's stronger ink checks.
- `tests/util/measurer.test.ts:37–67`: fallback-font lifecycle, useful for browser hosts without importing ambient mutation into deterministic Native profiles.

The demonstrated missing interaction is **candidate change × compact face capacity × foreign-route clearance**, not a lack of isolated port or marker tests. Existing generic zero-crossing comparison tests (`layout-certification.test.ts:334–358`) do not protect the Native owned-refinement gate. Add coverage at that owning boundary only when implementing its policy change.

**Practical adoption:** a reliable Native subset is plausible; existing omitted-backend forest paths already bypass ELK. But small-graph counterexamples prevent declaring a family or size threshold safe, and partial Trident fidelity does not establish that boundary. Keep Native opt-in, fix coupled visible defects, and qualify an intended workload with explicit quality tradeoffs. Default readiness requires clear final output and acceptable consumed-product costs, not universal Pareto dominance over ELK. Pele's lesson is coherent producer ownership and a clear product contract.
