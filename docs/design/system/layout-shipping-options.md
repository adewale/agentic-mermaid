## B: exact behavior that would need owner review

The existing seam already provides the required error/fallback distinction: `runMeasuredGraphBackend` in `src/layout/backend.ts` catches `GraphLayoutUnsupportedError` only for explicitly permitted `fallback: 'elk'`; the general graph path separately permits known certification rejection. Unexpected errors, invalid inputs and dependency loads must retain their present behavior. No universal catch, ELK race or automatic fallback is proposed.

A structural preview would preserve:

- Omitted `graphLayout`: the integrated default policy, including the guarded forest path. Explicit ELK: ELK. Explicit native: native only within the declared capability; otherwise typed capability decline. Explicit native plus ELK fallback: one attributed transition, unchanged authored subjects/relationships and retained diagnostics/receipts.
- All validation, relationship directions, measured labels, visibility, group membership, rank/route contracts and final paint/geometry certification. A cycle is declined as a whole, never “fixed” by deleting relationships. `TypeError`/malformed-input precedence remains ahead of capability decisions.
- A gate before the self-loop expansion at `agentic-layered-core.ts` and before any expensive cyclic search. The present Kahn check occurs **after** compound and loop handling, so merely replacing `layoutCyclicGraph` at that site does not implement an acyclic-only contract. If compounds are admitted, `agentic-compound-core.ts` lifts edges to ancestor scopes: authored-leaf acyclicity alone does not certify every quotient scope. Initially declining compounds is simpler and honest, with explicit coverage loss.
- Every historical27 input from `layout-review-population.ts`, plus existing supplements and controls. Record native successes, typed declines, fallback attempts/outcomes, input errors, timeouts and nulls individually. Keep strict-native decline counts in the denominator; never award unsupported inputs a speed or quality win. Preserve the six cyclic Flowchart tails as visible declines and benchmark the actual fallback arm against ELK. Do not filter the population to DAGs and call it full27 success.
- A new implementation/capability identity in decisions and backend-aware cache keys. Current `agentic-layered@26` cannot identify a behaviorally narrower preview. Node, IIFE, lazy browser, CLI/MCP, terminal companion and receipt paths must agree. No inference from a successful native render to ELK download avoidance.

Neither removing cyclic search from supported behavior nor rejecting it at runtime proves that it disappears from the built closure. Static imports in the core/lazy producer must be reviewed, and actual artifacts measured. Shared preparation, routing, label work and certification remain for admitted DAGs. This proposal has **zero measured savings so far**.
