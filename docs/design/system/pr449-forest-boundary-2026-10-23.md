# PR449: forest delivery boundary and the remaining ELK deficits

[Portable evidence and verification](https://github.com/adewale/agentic-mermaid/blob/a6b9b14161bd281804d5f2c9149320dfd882eb0f/docs/design/system/pr449-forest-boundary-2026-10-23-evidence.md)

The qualified source change is [678af21d](https://github.com/adewale/agentic-mermaid/commit/678af21d8f2fc4de62f6dcf98d7f0489c8cde9c0), based on d6a9a759 and main 861375d3. It moves the shared forest implementation behind one existing-demand browser loading boundary. Architecture with ELK downloads **1,002 fewer Brotli bytes**, retaining 34 module requests and all unchanged delivery caps. Native Architecture costs **296 additional Brotli bytes and one additional request**. No layout algorithm or default backend changes.

ELK remains the default and supported fallback. Flowchart, State, Class, ER, Requirement and Architecture remain native opt-in families. This milestone does not establish universal native superiority over ELK, a new speed improvement or a qualified peak-memory advantage.

## What changed and passed

Both the explicit native producer and the default indexed-forest experiment use the shared forest loader. The default experiment already includes indexed layout: its new demand must be measured. Native loading acquires producer and forest together; it does not consume another deferred-dependency event. The three-event ceiling remains unchanged. Canonical Node and synchronous editor entry points retain their eager implementation.

Native Architecture's selected delivery is about 56.2% smaller than selected ELK. This is a browser demand-closure comparison, not the size of the complete package or a fallback session. Native plus fallback must still acquire ELK.

The first canonical six-step build and strict report passed all 23 browser delivery caps and the unchanged standalone limits. The owning suite passed 164 tests and 5,274 assertions, both typechecks and affected lint. Independent readback verifies every one of 136 first-built files and 104 literal cap checks. No successful alternative build was selected.

The ordinary proof reuses the original ec72 packets and compares all 300 complete values, 1,200 SVG/receipt/layout/layout-receipt UTF8 payloads and 60 trusted-host callback packets. All match, including 48 successes, 12 expected native error packets, stateful measurements and reentrancy.

Actual Chromium 154 checks both ELK cache settings with default experiments unset. These browser settings are distinct from ordinary Node OFF, which explicitly selects text-spans only. Both browser policies pass: 120 complete paired packets, 232 UTF8 comparisons, 60 cold/warm pairs and two fresh-context fault recoveries. All 4,240 request records and 124 closed contexts validate. Architecture default/ELK stays at 34 requests; admitted native and implicit forest paths add one forest module.

The explicit native→ELK→HTML chain is observed. The separate positive-spacing default forest+HTML probe never reaches ELK, so the implicit default forest→ELK union remains source/metafile-budgeted, not an observed fallback path. A failed forest import remains rejected in the same context; a fresh context recovers exactly. Resetting a loader promise is not a guarantee that browsers retry a rejected ESM module.

The first browser harness attempt failed before Playwright import: controller and worker both claimed output-directory ownership. Its original failed ledger, zero process exit despite failed state, negative assessment and missed review are retained. Browser-only v2 corrects ownership and propagates failure exit status, preserving the same product artifact, cases, budgets and gates. A fresh-directory process fixture discriminates the old controller statement. The successful ordinary/host campaign is not rerendered.

## New measurements that did not qualify

The [complete selected RSS and hosted timing evidence](pr449-controls-2026-10-23.md) is available separately, retaining every worker and failed control.

The new RSS instrument uses cold Python exec, an explicit fork, then pinned Node. This removes the inherited lifetime-highwater contamination demonstrated by the original instrument controls. Node SELF peak is sampled after all consumed outputs, checksums and oracle checks, before result JSON. It includes Node, module loading, harness work and natural GC; it is not renderer-only memory. Bridge SELF and child wait4 remain separate.

All 24 workers finish the same original 75-input one-pass session, with no prewarm or forced GC: all 1,800 SVG/full-receipt calls, output hashes, floors, deadlines and output budgets pass. Four mandatory reciprocal 5% A/A controls fail: native and ELK in round one of both policies. The lower median ratios are descriptive only. No round is dropped, metric substituted, threshold changed or campaign retried.

The separately declared [hosted baseline calibration](https://github.com/adewale/agentic-mermaid/actions/runs/40019468597) also completes all 24 workers and 10,800 consumed calls: 3,600 warm and 7,200 timed. Its unchanged assessment fails 75 controls: four H27 aggregates, 54 per-input medians and 17 tail groups, containing 24 bad individual rounds. All 12 whole-75 and 12 D48 aggregate controls pass; these do not rescue the failed H27/input/tail gates. Two earlier hosted preparations stopped before any renderer/oracle/timing workers and remain retained.

The hosted artifact is rebuilt from pinned source and dependencies; it differs from the old local distribution. All 300 strict tagged semantic values and 1,200 UTF8 payloads match. Twenty-eight V8 serialized hashes differ while the declared tagged structures match. Live identity/aliasing and pre-V8 descriptors are outside this comparison; V8 bytes are provenance, not canonical values.

Offline analysis finds an initial timed-pass trend and substantial cross-process dispersion. Forty-three of 54 failed input groups change B/A sign across rounds. Symmetrically dropping the first timed pass still fails 55 input, five aggregate and 15 tail controls. That sensitivity is not a replacement assessment or evidence for a chosen warmup fix.

## Further ideas, with their current decisions

All 17 open issue/PR discussion feeds were refreshed at 20:54 UTC: 49 comments, one added since the previous refresh. The new [integration review](https://github.com/adewale/agentic-mermaid/pull/433#issuecomment-6373722958) warns against stacking overlapping scanner/security implementations or adding compressed savings. Its optional-parent matrix boundary and editor headroom are integration risks, not permission to merge other PRs.

| Idea or experiment | Evidence and decision |
|---|---|
| Remove discarded route-port plans | Baseline observer preparation passes independent review; actual owning census remains unrun |
| Reuse a previous blocking node | Exact observer retains all original work; predicted net node savings are under 1% before other bookkeeping. No product prototype |
| Reuse custom Boolean queries | Corrected host-only observer preserves all original packets but finds zero hits in 6,776 custom-active queries. No product memoization |
| Restrict native to DAGs | Offline policy would lose the seven native-only cyclic successes and sacrifice most crossing gains. Not adopted |
| Reuse ER label ownership | Already implemented in accepted runtime; ER40 has zero current foreign-shaft label conflicts. Repeating the fix is rejected |
| Reduce ER tree bends | A new flat, equal-card labelled binary-tree prototype aligns one authored child, retaining distinct ports and final validation. Tests/delivery are the next gate; geometry and cost remain unqualified |
| Apply sparse visibility routing to cyclic tails | Current cyclic core emits channel tracks directly; actual grids belong to Architecture and compound repair. No demonstrated cyclic-tail owner |
| Hardcode ELK constructor defaults | Raw synchronous dispatch bypasses constructor defaults; broad explicit defaults add work or alter scope. Not adopted |
| Lazy YAML from #471 | Real lead: 74 YAML metafile inputs share a 129,216-byte chunk. Literal integration conflicts with native/forest providers and can require a fourth deferred event. A compatible readiness design is still needed |
| Rebuild/specialize ELK | The bounded infrastructure attempt passes in 30.873 seconds; exact image, Node binary, resource settings and private quota verified. Compiler reconstruction and specialization remain unrun |
| Profile RSS/GC by input | The [four-worker structured diagnostic](pr449-gc-diagnostic-2026-10-23.md) completes all 300 calls, 600 anchors and 608 snapshots. It locates large Requirement100/cyclic/DAG windows; observer overhead prevents a performance or memory-win claim |

The ER prototype deliberately explores a tradeoff: target actual bends no worse than ELK, area no worse than ELK and at most 1.15× current native, length no worse than either, with no new hard geometry or coverage loss. Its simple bounds fit that area allowance; actual legal geometry is unmeasured. It bypasses the generic geometry cache, so warm-cache performance could worsen. No source-name dispatch or lost relationships are permitted.

The remaining work includes cyclic latency/allocation tails, long routes, per-input quality deficits, reliable new cost measurements, paint uncertainty and cross-contract community comparisons. This is an active frontier, not a claim that the literature or community ideas are exhausted.
