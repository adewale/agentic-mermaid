# Native layout: 0.6 qualification contract

Status: owner-directed **0.6.0** work, 27 October 2026. This is an acceptance
contract, not completed qualification or a second backlog. The sole backlog
owner remains [Owned graph backend qualification in TODO.md](../../../TODO.md#owned-graph-backend-qualification-owner-request-pr-449).
PR [#449](https://github.com/adewale/agentic-mermaid/pull/449) stays draft;
ELK remains the default. This programme is not a 0.5 publication condition.
It changes neither the package version nor the default backend and performs no
publication. Feature qualification and the release publication procedure remain
separate decisions.

## Six acceptance contracts

| Owner goal | Required evidence |
| --- | --- |
| 1. Fix coverage gaps | A registry-derived family/feature/execution matrix with independently expected meaning, witnesses and explicit unsupported or missing cells. |
| 2. Establish broader correctness | A prospectively frozen independent holdout, no demonstrated incorrect accepted output and no Native-only loss of admission within the claimed supported domain. All failures, refusals and unknowns remain enrolled. |
| 3. Match or beat ELK aesthetics | Per-family metric vectors and independent blinded task/readability evidence meet predeclared non-inferiority criteria. Superiority requires separate evidence. |
| 4. Match ELK performance | Fully consumed public outputs meet calibrated per-case/family parity bounds across cold, warm, cached, edited and churn regimes. Memory and browser delivery are separately qualified. |
| 5. Verify the seven diagrams | Sound final-artifact certificates and independent actual-ink review for every source under both engines/cache policies, with unchanged production limits. |
| 6. Compare correctness with Mermaid and Pele | Independent author intent checked through public models, rendered occurrences and visible ink in pinned public artifacts. Report full and shared-supported/observable populations. |

All six remain open. Earlier instrumentation, tests and repaired examples do not
complete this contract. A narrower family policy may be evaluated prospectively;
deleting adverse inputs or counting ELK fallback as Native completion cannot
satisfy the existing target.

## Coverage and generalisation

Extend the existing [family conformance planner](../../../src/__tests__/helpers/render-conformance-plan.ts),
family risk profiles, model/source-preservation properties,
[graph fixtures and generated stress cases](../../../eval/layout-compare/generated.ts)
and pinned external corpora. Derive applicability from runtime descriptors;
do not maintain another copied registry or add a test-presence gate.

At this baseline the selectable families are Flowchart, State, Class, ER,
Architecture and Requirement. Block and other non-consuming families retain
common rendering coverage. Cross strict Native and explicit ELK with cache
OFF/NORMAL; explicit fallback is a separate arm paying and reporting both
attempts. Exercise SVG, raster and both terminal glyph sets according to their
actual producer/companion roles.

Verify the actual lowered font, stroke width, marker units, selected backend
and cache policy before assigning an observation to a matrix cell. Public
StyleSpec fields and internal resolved-style fields are different boundaries;
an ignored requested field must not masquerade as a tested styling condition.

Cover shapes, direction aliases, cycles, loops, parallel/reciprocal edges,
dense fans, nested/ancestor scopes, authored sides and constraints, namespaces
and shadowed names, long/Unicode text, members/cardinalities/notes, marker kinds,
global/thick/inline-fixed widths, rounded/curved output, explicit measured sizes,
source wrappers, source/JSON reload, edits and undo. Use pairwise coverage plus
mandatory higher-order cases around demonstrated seams: nested fans with wide
heads; namespace/header/cardinality paint; sides with junctions; dense labelled
cycles with terminal connectivity. Pairwise coverage alone is insufficient.

Generate expected identities, ordered relationship occurrences, immediate
parents, directed ends, labels, members and marker meanings before using our
parser or renderer. Extend Class generation beyond small loop-free graphs to
dense relations, interfaces, namespaces, notes and self-links. Keep malformed
input rejection distinct from valid admission. Use meaningful metamorphic
relations for spelling, caches, reload and edit/undo; source order can matter,
so statement permutation does not require identical layout.

Freeze grammar, factors, expected facts, seed policy, dependencies and resource
bounds before acquisition. Reserve a holdout built with a different construction
method and newly pinned external examples. Freeze the candidate revision,
claimed family/feature domain and outcome rules before unsealing holdout sources
or results. An independent custodian records the sealed artifact identity and
access; informative inspection before candidate freeze makes it development data.
New seeds alone do not establish independence. Size strata for their claims and
pilot variance. Once a holdout informs a repair it becomes development data;
retain it and declare a fresh confirmatory cohort. Shrinking a failure never
removes its original observation or changes the claimed domain after results.

Report every enrolled outcome separately: correct under stated checks,
demonstrated incorrect, unverified, typed unsupported, resource exhaustion,
unexpected error and unavailable observation. Genuine inapplicability is
separate. Publish all denominators and unfilled matrix cells. Extra Native
refusals on valid ELK successes remain coverage gaps inside the claimed domain;
an incomplete campaign remains incomplete.

## Seven unverified diagrams

The source rows are 77, 87, 88, 89, 103, 206 and 209, with 26 issues. IDs name
regression witnesses; they must never select implementation exceptions.

| Group | Shared production obligation |
| --- | --- |
| Ordinary thick arrow and supporting cylinder sides | Bind exact emitted coordinates, width, resources, identity, owner, ancestry and header context to the same emission; check all written body pieces. |
| Circle/cross stroke-only markers | Establish actual nonempty visible stroke witnesses, viewport clipping, caps and complete owned-border paint without inventing an opaque fill. |
| Typed cubic terminal | Derive orientation from emitted controls, including collapsed-derivative fallback, while retaining complete path bounds and SVG direction semantics. |
| Cylinder/ellipse contacts | Prove the emitted rectangle/ellipses/side-stroke union, then analytic off-support contacts; forbidden fill intrusion or semantic ink loss outside the existing attached-border contract needs a producer repair. |

First prototype one occurrence-bound same-emission authority for existing
proofs, initially line/polyline and supporting-body cases. Reuse exact retained
fragment/resource bytes and typed serialization; avoid another geometry writer
or global node-identity proof cache. Mutable/getter callers, repeated writes,
mismatched definitions, inherited CSS and unknown transforms retain fresh
strict behaviour. Then extend stroke witnesses, cubic terminals and full
compound-body proofs.

Do not round away or shrink supplied conservative marker bounds. Union them
with the fresh complete served envelope unless containment is proved; reduce
them through clipping only when the actual viewport intersection is independently
established. Revalidate the same nonempty visible-ink witness used by the proof
(opaque fill or opaque stroke as appropriate) against every served child and
its full stroke/cap envelope. Raw-space witnesses cannot be borrowed as served
proofs. Legitimate owned outline-band contact can have positive area; preserve
its existing precise admission contract rather than banning or excusing every
intersection by ownership alone.

Retain mutation, reused/reordered ownership, rounding-up, hidden ink,
internal-line, viewport/ref-point, dash/unknown-width, reversed/degenerate-curve,
inward ellipse and budget-exhaustion controls in existing owning tests. Require
genuine old U/failure to sound P at the public emitted boundary, not helper P
alone. Proof-only fixes preserve SVG bytes; geometry changes need independent
actual XML and bundled-font raster review. Qualify every remaining issue in all
seven sources under both engines/cache policies, with unchanged 400,000-operation
and other limits. No epsilon, higher cap or producer-name exemption closes a gap.

## Aesthetic qualification

Use independently qualified paired outputs for aesthetics while reporting
availability over the full population. Pin fonts, appearance, direction, seeds
and viewing conditions. Publish per-case/family raw and normalised vectors:
crossings; bends/length; shared/opposing ink; area/aspect/spacing; appropriate
ports and symmetry; grouping; label readability/association; and edit stability.
Retain win/tie/loss counts, tails and worst cases. Raw and translation-aligned
movement, order and attachment changes are separate. No weighted aggregate can
hide a bad family or demonstrated drawing defect.

Prepare anonymous randomised A/B material for an independently arranged human
panel. Counterbalance path/relationship tracing, cardinality, label ownership,
containment and locating edits. Each participant performs comprehension tasks
on one assigned arm per source before seeing paired preference material, or use
separate task/preference panels to prevent learning from the other rendering.
Native-size pan/zoom and fit-to-window are different viewing conditions. Existing
labelled galleries and periodic LLM ratings are diagnostic, not blinded proof.

Use a finite pilot to estimate variance and determine confirmatory sample sizes.
Acceptable loss and practical non-inferiority margins come from task/user
requirements or blinded perceptual calibration, never observed Native deficits.
Freeze them before confirmatory candidate outcomes.
Intervals must account for source/reviewer clustering, correlated variants,
errors/timeouts and multiple superiority claims. Require family/task
non-inferiority and adjudicate substantial individual regressions. Claim
superiority only where its independent criterion passes. Report the
crossing/bend/area frontier rather than treating every metric as monotonic beauty.

Reuse [paired comparisons](../../../eval/layout-compare/run.ts),
[edit sequences](../../../eval/layout-compare/edit-sequences.ts), stability,
the existing rubric and visual tools. Purchase's task-dependent crossing results
and mental-map research motivate separate measurements, not universal weights.

## Performance qualification

Shared runner changes belong in [Trident](../../../eval/trident/README.md).
First version the full-consumption/completeness adapter: the older release
worker's SVG-return clock with later hashing is not this gate. Include the call,
realised receipt, SVG UTF-8 and entire receipt JSON UTF-8 consumption/checksum.
Keep import/startup, first complete output, warm recompute, exact repeat,
semantic edit/undo and eviction churn as separate cells.

Primary parity uses the same candidate artifact with strict Native versus
strict ELK and matched actual ELK 0.11.1. Shipping main's checked lock resolves
0.11.0 and is a separate regression arm; verify each installed and emitted
closure, since a package range proves neither. Dependency-normalised main is a
controlled variant, not shipping main. Verify actual selection; explicit fallback
pays both attempts and never counts as strict Native completion.

Use two independent A/A controls plus A/B, at least five counterbalanced fresh
process rounds, both cache policies, and precise per-case tails. Proposed
initial non-inferiority ceilings are p50 at most 1.05x, p95 at most 1.10x and
allocation at most 1.05x matched ELK. These are proposals, not measurements or
claims of identical speed; final practical bands must be calibrated and frozen
before candidate data. Excess noise leaves a cell unresolved, never widens its
band. The legacy 1.5x safety ceiling is not parity.

Require every mandatory case/family/regime, not a corpus average. Retain
adverse/incomplete workers without retries, deadline rescue, trimmed rounds,
eligibility shrinkage, cross-host pooling or division by A/A ratios. Five rounds
do not automatically establish p95 precision; mixed-case p95 is not a per-case
tail. Measure allocation, settled/post-eviction heap and fresh-process RSS
separately, with prospective practical and near-zero rules. Process high-water
and V8-only allocation cannot substitute for retention or other runtimes.

Measure real lazy/ESM and synchronous browser entries, initial/feature-union
requests, serial chains, compressed bytes, first use and retained realms.
Strict Native must make zero ELK requests. Deterministic caps get no noise
allowance or increase. Benchmarks remain explicit local campaigns outside CI.
After a qualified baseline, profile before tuning; test subtraction, proof/work
ownership, parameter specialisation and family portfolios one mechanism at a
time. Preserve negative experiments and their actual measured revisions.

## Correctness against Mermaid and Pele

Keep five public lanes distinct: our strict Native; our explicit ELK; Mermaid
with explicitly selected Dagre; Mermaid with explicitly selected ELK; and a
pinned published Pele. Verify actual algorithms/provider versions. Our ELK
pipeline is not Mermaid's ELK pipeline. Freeze renderer/provider artifacts
separately from the current Mermaid 12.2.0 syntax reference.

Historical Pele 1.6 measurements, the audited 1.9 adapter and 1.10 source review
are different evidence. Select and audit the actual published version before
enrollment; upgrading requires a new public-output schema review and controls.
The [current Pele adapter](pele-peer-observability.md) does not automatically
grant a future version complete rendered-geometry observability.

Reuse pinned Trident's authored
[fidelity campaign](https://github.com/adewale/trident/tree/0a0453c8cc64567d4ad1ccdc256035fb311cf31d/fidelity):
its cases, meaning, adapters, paint, protocol and criterion ledger declare 70
authored cases and 21 edits across 25 families. Those are existing inputs, not
an executed 0.6 result. Strengthen endpoint proximity to actual attachment,
partial marker mappings and missing ER crow-foot paint. Add distinct Mermaid
lanes and re-audit the selected public Pele artifact.

Check author intent to public model, model to actual owned rendered occurrences,
then visible ink. Include multiplicity, immediate parents, directed ends/authored
sides, label owners, marker/cardinality meaning, isolated declarations and
connectivity. Observe actual transforms, clipping, strokes, caps, fonts and
occlusion; bbox overlap is only a candidate. Public parser agreement, retained
labels and our own certificates are not substitutes for external observation.

Report full enrollment and the predeclared shared-supported, reviewed-observable
subset. Retain rejection, exception, timeout, unsupported syntax and unavailable
observations; genuine N/A, such as absent public ASCII APIs, is separate.
Validate observers with wrong ends, missing/duplicate occurrences and hidden ink
before acquisition. Record language quirks and intentional divergences without
rewriting author intent to match a peer. Neither pixel identity nor another
renderer supplies our correctness specification.

## Execution and evidence ownership

Start with extended coverage profiles/independent authored models, audited peer
adapters and a bounded Flowchart/Class/ER fidelity slice. In parallel implement
the first shared emission-proof prototype and prepare the aesthetic pilot.
Establish a descriptive baseline before solver tuning. After repairs, freeze a
candidate and fresh confirmatory holdout. Acquire controlled performance only
after correctness and agreed aesthetics pass on that same artifact.

Use the pinned
[Mermaid Community JSON](https://github.com/adewale/trident/blob/0a0453c8cc64567d4ad1ccdc256035fb311cf31d/catalog/mermaid-community.json),
[retained primary feedback](layout-exploration/community-primary-evidence.json),
[historical peer comparisons](layout-community-comparison.md) and academic work
as case/hypothesis sources. Recheck pinned public evidence when taking up an
idea. Shared ancestry is not independent algorithmic evidence.

Runtime fixes and counterexamples belong in Agentic's owning tests; shared peer
and measurement machinery belongs in Trident. Generated manifests, galleries
and raw reports stay external review artifacts, not new committed inventories.
Retain meaningful Trident owning tests for receipt consumption, completeness and
dependency validation; avoid tests of test presence or report self-validation.
Reports identify actual source/base/dependencies
and unavailable criteria. Follow [contract review and completion](../../testing-strategy.md#contract-review-and-completion)
and final-head CI. No newly measured win is claimed by this design.
