# PR #449 research archive — October 2026

These reports and offline archive verifiers preserve experiments from 23–24
October 2026. They describe the revisions, populations and failed controls named
in each report. They are historical evidence, not current performance claims,
development prerequisites or release gates. Do not rerun this campaign for an
ordinary renderer change.

For current implementation context, use the
[system architecture](../../../design/system/README.md) and
[layout backends](../../../design/system/layout-backends.md). For measurements,
use [Trident results](https://github.com/adewale/trident/blob/main/RESULTS.md).

The [forest boundary report](pr449-forest-boundary-2026-10-23.md) summarizes the
accepted delivery boundary and the still-unqualified cost claims. The
[geometry revision study](pr449-geometry-revision-proofs-2026-10-24.md) and
[pruned ELK study](pr449-pruned-elk-and-controlled-cost-2026-10-24.md) retain the
subsequent experiments. Follow their links for earlier scorecards and controls.

The three verifier scripts validate downloaded historical packets only. They do
not execute or qualify today's renderer. Raw packets, original report bytes and
their reproduction instructions remain in the
[immutable evidence snapshot](https://github.com/adewale/agentic-mermaid/tree/a6b9b14161bd281804d5f2c9149320dfd882eb0f/docs/design/system/).
Use that snapshot when verifying a recorded document hash; the copies here have
updated navigation links. Historical workspace paths and immutable URLs have
been retained as provenance.
