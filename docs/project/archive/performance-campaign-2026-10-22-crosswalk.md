## Twelve main recommendations

1. **Separate built-in imports from external admission.** A defers backend fixture construction until executable first use. It removes startup work, not the usable-family conformance dependency closure. Synchronous descriptor lookup and host registration still constrain a broader split. #433’s processor extraction remains separately owned; no material production payload reduction is claimed.

2. **Reduce native drawing copies and writer work.** B retains shallow group handles and occurrence traversal while preserving matrix/opacity arithmetic and ownership. The span/rope writer was tested and rejected after consumed-output slowdown with little allocation benefit. This does not remove every string copy or implement a new emission architecture.

3. **Emit typed attributes once and consolidate inspection.** K reuses raw XML attributes while preserving public envelope parsing, malformed-input precedence and final transformed-byte security. General color/ID/accessibility fusion remains absent. Host CSS, font configuration, opaque markup and style hashes prevent arbitrary transformation removal or reordering.

4. **Compute requested certification and retain trustworthy evidence.** C shares hard predicates and avoids discarded soft scoring. D privately retains positioned snapshots/projections for eligible internal borrowing; mutable public projections remain isolated. General geometry-generation proofs are unimplemented. #449’s rejected immediate-proof-reuse trial does not authorize caching certificates by mutable public identity.

5. **Optimize exact crossings and fixed obstacles.** #449 already supplies specialized native route-pair crossing queries; Node/IIFE and compact browser implementations have distinct qualification. Broader native indexing trials were rejected there. This campaign rejected its fixed-node bundled-label index. General ELK route/node/hitch indexing remains open; local H/L improvements do not complete it.

6. **Remove duplicate adapter ownership.** ER anchor preservation and Architecture placement-only layout are already #449 work, not outstanding campaign inventions. Its newer sibling repair still needs qualification tied to that source. #465’s drawn-contact/node-size authority must survive integration; older runtime measurements cannot establish current final-output behavior.

7. **Settle constraints before routing and update only affected work.** L maintains introduced overlaps around moved nodes using legacy ordering and numeric semantics. It still reconnects all edges. Supplemental ready-queue and local metadata changes are retained; forest preparation and classification reuse were rejected. Early settled constraints, shared adjacency/ancestry and affected-corridor routing remain broader redesigns.

8. **Control cache ownership and residency.** D retains private borrowing/public copying and five fixed estimated quotas totalling 36.25 MiB. This is simpler than the discarded coordinator, not tighter than its 32 MiB total. Estimates exclude live outputs, engine resources and bookkeeping. Miss ownership transfer, public renderer instances, clear/low-memory controls and geometry/paint separation remain unimplemented.

9. **Qualify native cohorts and investigate long-edge expansion.** The existing dense measured graph, Fenwick ordering and compound kernel belong to #449. Native remains opt-in; there is no default promotion. Architecture/cyclic tails, compound fallbacks and sparse long-edge normalization need owner-specific evidence. Instrument expanded vertices and total spans before selecting a replacement algorithm.

10. **Remove repeated specialized-family collection work.** Retained changes cover Gantt section grouping/adaptive first-fit lanes, GitGraph extents, lazy Quadrant candidates, calendar skipping, iterative dependencies and large-chart collision filtering. Sequence scalar maxima, Sankey bucket appends, ASCII frame aggregation and graphical overlay indexing were tested and rejected. Traversal is retained for demonstrated compiled-Node stack recovery, not scheduler throughput.

11. **Optimize editing, terminal, MCP and acquisition boundaries.** E retains family-owned batch drafts; H assertion-local proof indexes; J thin help/error dispatch; M safe lazy collection traversal, including six recovered baseline Map failures. F memoization was rejected; the no-directive restoration return remains. Unsupported `--version` stays an error. No speed ratio uses a failed baseline.

    A private SVG-only acquisition probe used unchanged ab3 runtime/declaration bytes, fresh installations, 23 family SVG/receipt checks and isolated strict TypeScript consumers. It demonstrates narrower installation acquisition, not a production package/browser improvement or equivalent API scope. PNG packaging and the existing primary package remain unchanged; distribution/platform support still requires a product decision.

12. **Make competitiveness and scaling persistent goals.** The campaign completes broad before/after measurement, coverage and payload evidence, but does not install new calibrated semantic/peer/tail/allocation gates or systematic cache-hit, solver-eligibility and repair/fallback reporting. Existing slowdown tolerances remain; peer results are advisory. Coordinate calibration with #433. Acceptance and surviving labels do not establish equivalent edges, ports or containment.

## Eight architecture recommendations

1. **Hard-only certification and private evidence.** C/D implement the bounded subset above. Full quality consumers retain soft scoring. Reusable native candidate proofs still need immutable owned artifacts and complete source/style/font/backend dependencies; layout proof cannot substitute for final paint or source-correspondence evidence.

2. **Compile pass metadata and make changes explicit.** A local request-building loop removes temporary collections. Once-only compilation of the exported mutable plan is absent. Pipeline-wide epochs, narrow snapshots and immutable dimensions plus translation remain open. Declared mutation metadata cannot replace checking actual geometry or observing live callback/budget behavior.

3. **Use one render-owned graph workspace end to end.** This remains unimplemented. Conversion and repair still rebuild representations. Forest/classification wrappers were evaluated and rejected for cost, with an additional forest callback-observer hole. Those results reject the concrete wrappers, not every future design that removes an owning representation.

4. **Improve source ordering without changing edge roles.** The stable ready min-heap replaces repeated ready-list shifts/sorts. Per-edge reachability remains. Guarded classification reuse was rejected because validation overhead outweighed common-case recomputation. Incremental topological ordering and bounded bitsets remain absent; neither deterministic DFS orientation nor historical rank-rewriting prototypes preserve the required contract automatically.

5. **Move minimum spans before routing.** L addresses repeated overlap repair only. Moving constraints into ranking/placement changes output and requires native authority or a separately qualified compatibility option. Selective rerouting must include nonincident routes affected by old/new obstacle corridors, not merely edges attached to moved nodes.

6. **Index spatial queries at mutation boundaries.** Quadrant’s invocation-local buckets are retained in that family. The general ELK fixed-node bundled-label trial was rejected after actual-owner regressions; route/label/hitch indexes remain absent. Exact predicates and original diagnostic order remain mandatory after any broad-phase query. Native ownership does not reserve unrelated ELK owners.

7. **Execute measured-graph/direct-adapter work.** #449 implements its own measured layered producer. A direct forest-to-positioned path remains absent: the tested preparation subtraction lacked convincing gains and exposed observable missing ELK context. Future conversion removal must preserve #465 node sizes, Architecture junctions, custom profiles and mutable extension behavior.

8. **Expose cache residency as a product choice.** Private reuse and fixed quotas are retained; renderer-instance lifetimes, documented clear/low-memory controls and paint/geometry dependency separation are not. Exact-repeat latency and unique-source churn remain distinct evidence. More cache capacity cannot by itself demonstrate lower first-render cost, download size or process residency.

## Supplemental dispositions and remaining risks

The main report’s supplemental table records all ten additional trials without treating A–M as an exhaustive initial queue. Five are retained: the ready heap, local metric requests, Gantt calendar skipping, iterative Gantt traversal and Quadrant collision buckets. Five are rejected: reduced forest preparation, classification reuse, bundled-label indexing, ASCII frame aggregation and graphical Sequence overlay indexing. All ten completed source-owner evaluation; the five retained changes also completed combined packed confirmation and full replay. Detailed numbers and adverse controls belong to their respective protocols.

Traversal’s demonstrated recovery is a compiled Node 10,000-task library witness exceeding hosted admission size. Smaller cases and the Bun regression guard succeed on both versions; they are not recovery evidence. Public Gantt receipt timing remains unresolved. The separate official Gantt150 repeat is also adverse with an unstable A/A control, so it did not satisfy the declared attribution trigger. The large terminal repeat is mildly adverse with mixed direction and an unstable control; it does not reproduce the original magnitude or qualify the declared attribution experiment. These limits preserve the adverse observations rather than establish that regressions are absent.
