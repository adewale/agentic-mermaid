# SVG pipeline campaign disposition

PR #433 originally introduced private lexical recipes to replace the older
parallel SVG strings. Main subsequently introduced native drawing through a
shared typed `DrawingFactory`: crisp drawing no longer retains a Scene group
tree, and public marks serialize from their current semantic fields.

Rebasing the recipe migration onto that implementation left extra capture,
decoration, interpretation and validation work in the drawing stage. It also
omitted supported public paint/transforms/hooks, replayed historical Class
operands, exceeded browser payload limits, and changed unchanged goldens.
The private recipe implementation and its representation-specific tests are
removed. Native public behavior, security, rendering goldens and benchmark
populations remain protected. Exact built-in backend identity and retained
admission-strength checks are kept.

## Measurement contract

The fixed historical source baseline remains
`a9d1551da27ddab542a1ae96329464ad65725448`. Current-main comparisons are separate;
upstream improvements are not gains from this PR. Production measurements use
Scene assertions off and record ELK cache policy explicitly. Installed artifact
measurements, source-stage diagnostics and browser measurements are separate.
Complete output and receipts must be consumed; corpora, goldens and release
budgets are unchanged.

The completed pre-removal campaign at
`7035cdf0ea68725fc9958f455ebfb5ae3b0ce6c3` failed performance gates: 1.305× current
main Node corpus time, 1.223× current main browser corpus time, and 1.116× the
fixed historical baseline with cache off. These results describe that revision,
not the subsequent fix. Source-stage diagnostics locate large additions in
Sequence, Class and ER drawing, with layout similar or lower. They are
instrumented diagnostic passes, not a replacement for packed release gates.

Reproduction and the original campaign evidence are in
[Trident `RESULTS.md`](https://github.com/adewale/trident/blob/main/RESULTS.md). Performance targets
remain unproven until an exact clean candidate passes the unchanged gates.
