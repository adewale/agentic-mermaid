### Original tests, reuse and interpretation

The genuine pinned Mermaid core Vitest baseline executes **331 files**:
**6,677 passed callbacks, 16 pending, two todo, zero failures or unavailable
files**. All **99 snapshots match**; none were added or updated. The unchanged
3,995-declaration source census separately accounts for discovery and location
mapping. These expanded callbacks are not individual assertion invocations.

The public-model original-callback projection spans 85 files and 2,700 expanded
callbacks per core tool. On **1,555 reference-passing callback occurrences**,
Mermaid passes 1,555, Pele 1,440 (seven mismatches, 108 unavailable), and Agentic
790 (510 mismatches, 255 unavailable). These are strict original-expectation
compatibility results. Of Agentic’s 510 mismatches, 459 concern Flowchart private
DB representation; they are not 459 independently demonstrated drawing defects.
The authored meaning/paint campaign provides a separate correctness dimension.

Exact repeats reuse all three core fidelity records, all 40 community records,
the genuine source baseline and all three public projection records. Original
IDs, dates and raw observations are preserved. Community attempts remain **40→40**.
One completed publication interrupted by ENOSPC was recovered through the real
publication boundary after two-agent verification; no renderer rerun or invented
failure receipt was used. Original failed status, orphan and failure evidence remain.

What this taught us: observer correctness needs adversarial drawing mutations;
valid SVG/text is insufficient; a tool’s private representation is not drawing
meaning; an export name is not option support; and cache composition time is
not measurement time. Report composition reconstructs missing criteria/projects
and checks the actual authored/observer/browser receipt before comparing.

Remaining scopes include browser/e2e upstream tests, private APIs, complete custom
paint and typography/accessibility review, larger feature combinations, and
whole-browser/native/GPU memory, leak slopes and deployed costs. Terminal/parser
and editor tools retain their own invocation/cost lanes, not invented SVG scores.

## Pinned Mermaid baseline, 25 October 2026

Pinned **Mermaid 12.2.0** is the reference, with cost **1** in each matched lane.
Lower cost is better. Coverage uses its full declared denominator and the
observed difference from Mermaid; it is never assumed to be 100%.

This set uses Pele **1.9.0**, Agentic **0.4.2** from product source
`f8a2437b19e67a850145b786f72baf719da52837`, and the pinned Mermaid source

these scopes. These observations do not compare equal AST outputs, isolated API

### Wider community and remaining limits

The separate historical reduction retains **88 current catalog projects**:
84 have earlier evidence and four remain unmeasured. Only **25 independent
implementations plus four attributed aliases** qualify for the six-input
browser SVG cost comparison. Its leading independent ratios are Bezel **0.0012**,
Ondine **0.0014**, Pele **0.0018** and Frankenmermaid **0.0027**, versus Mermaid 1;
Agentic is **0.0411**. Those October 24 artifacts, inputs and three-round windows
remain historical and are not merged with the current 48-case experiment.
Parser-only, terminal, editor and core-Mermaid-absent API boundaries are unranked
where no common Mermaid operation exists.

The broad historical qualifier admits Mermaid on **855/963** fixtures; 77 fail,
30 are parser-only N/A and one is unsupported. Source/configuration quirks and
qualifier weaknesses need review. A peer with more admissions has not thereby
proved better Mermaid fidelity. The original-assertion projection covers only
**99 of 3,995** inventoried declarations. Full feature combinations, independently
reviewed community paint/meaning, whole-browser/native/GPU memory, leak slopes,
concurrency and deployed costs remain incomplete. See the
[assessment](https://github.com/adewale/trident/blob/main/ASSESSMENT.md) and
[overview](https://github.com/adewale/trident/blob/main/OVERVIEW.md).
