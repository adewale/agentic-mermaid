# Five Native marker-envelope regressions: isolated cause

Bounded acquisition: five named historical P/current U cases, current runtime plus the root-owned body-gap repair. Public renderMermaidSVGWithReceipt, Node24 source loader; no performance acquisition. Source production unchanged by this investigator.

## Exclusions and cause

Omitted fallback versus explicit `none` produces byte-exact SVG and entire receipt on all five. Current adapter defaults omitted fallback to none (src/layout/backend.ts:58; render-contract.ts:1243).

Overriding ONLY measured-graph-producer.ts with exact 03b7b35d3 parent restores all five P. Current producer has no subsequent diff from03b. This isolates commit03b7b35d3's authored-end capacity change, not the new body-gap repair.

First responsible interaction: producer lines306–331 now emits node.minimumPortSpacing for newly supported thin spans<=8. assignPorts in src/layout/agentic-layered-core.ts:717 first tries 8px-or-greater neighbor spacing. On a dense face that fails; line729 permits weighted per-edge span packing ONLY when minimumPortSpacing is undefined. The new scalar therefore disables known physical per-occurrence packing and falls through to proportional spacing at746–749. Examples: cyclic3 adjacent warned tips6.322→5.25px; cyclic3536.322→4.5; SHA109/1276.519→5.063. This is not evidence that the newly reserved body size should be rolled back.

## Small sufficient counterfactual

producer-weighted.ts changes only `node.minimumPortSpacing = pitch` to `if (span > 8) node.minimumPortSpacing = pitch`. It retains authored-end thin-head body growth, per-edge physical spans, all ledgers/caps and preexisting wide-head scalar behavior. The existing weighted allocator becomes eligible again. All five return/P under this override. This is an external diagnostic, not qualified production.
