# Proposals after integrating main c366

The absence of a universal layout plug-in API is not itself a demonstrated product defect. Shared selection, typed fallback and substantial family conformance already exist. Current main strengthens this with explicit placement-only family paths. Do not make a new solver framework the prerequisite for further repairs.

| Earlier proposal | Decision after rebase | Concrete next evidence |
|---|---|---|
| One solver contract and shared conformance suite | **Narrow and fold into owning work.** Keep neutral measured obligations where adapters duplicate them, distinguish placement from completed routes, and reuse existing parameterized family tests. No new registry or qualification framework now. | An adapter migration that currently cannot state or check a required distinction. A third solver can be a future consumer, not a speculative requirement. |
| Producer clearance, ports and alignment | **Keep as a targeted geometry hypothesis.** Main improves Class label halos and ELK Requirement marker reservation; those are already implemented. Native's generic producer remains unchanged by the new main commits. | An alternative that removes the demonstrated half-rank floor waste while preserving physical spacing, alignment, meaning, final contacts and preferred bends. The diamond still trades 2 bends for 4, so it is not a production fix. |
| Profile and subtract duplicate completion | **Keep profile-first; narrow by task purpose.** Swimlane already skips generic routing and owns lane routes. Do not force it into a complete-graph result or skip verification wholesale. | Fully consumed stage attribution and a subtraction experiment that materially changes cost without losing final-output obligations. |
| Sparse long-edge representation | **Defer until expansion is material.** The paper supports reducing normalized representation size; it gives no speedup for our bounded domain by itself. | Virtual V/E, cumulative rank span, ordering time, allocation/peak memory. Preserve labels, hierarchy, offsets and exact caps. |
| Missing interaction tests | **Fold into each fix.** Main adds four-direction Native/ELK selection/contact witnesses and explicit conservative exclusions. Existing tests already protect much of the requested behavior. | A reproduced combination existing coverage misses. This rebase supplied one: metered final XML work after a layout query on generated case 255. Parent Scene-assertion passes were not enough; the real Native child witness discriminates it. |
| Dependency closures and payload | **Keep as a substantive measured deficit.** Actual standalone gzip improves against new main, but Brotli worsens and the retained gzip ceiling fails. | Compare actual transport/offline artifacts, module closures and fully consumed decode/render costs. Keep common dependency versions and output work explicit; do not infer runtime from compressed bytes or raise the ceiling. |
| Phase states, objectives and candidate history | **Small diagnostic work, not replacement progress.** Preserve the prior internal search-history finding; new main does not change that producer. Broader phase architecture is unnecessary without a concrete failure. | One real multi-candidate witness retaining honest search history through fresh final certification, with unchanged geometry and separate backend/paint attempt meanings. |

**Retire duplicate ER indexing proposals.** The shared ink index and indexed-prefix ER caption planner already match main. Retain PR-specific island packing, ancestor contact handling and cardinality identity; do not replace whole files with main just because the index work overlaps.

The visible forest and Class gains still reproduce against new main, with the Class height cost explicit. They justify retaining those changes. They do not justify treating every metric difference from ELK as a bug, expanding the campaign automatically, or calling the PR a general ELK replacement. The next implementation should address one measured remaining delivery/resource or visible loss, rather than begin all seven proposals.
